# GeoFrame

**Self-hosted photo & video library** — умная галерея поверх вашей медиатеки. Укажите папку, запустите сервер, получите доступ к фотографиям с любого устройства в сети.

> GeoFrame — не облачный сервис и не файловый менеджер. Это индексатор, хранилище и веб-интерфейс для личной медиабиблиотеки, которую вы полностью контролируете.

## Зачем

- Хранить все фото и видео в одном месте на своём железе
- Не платить за облако и не зависеть от чужих сервисов
- Находить снимки по дате, месту, камере и другим метаданным
- Видеть фотографии на карте
- Разбирать дубликаты и серии снимков
- Получать доступ к библиотеке с телефона и компьютера

## Что это

```
                    ┌─────────────────────┐
                    │   geoframe (C++)    │
                    │                     │
Photos / Videos ───►│  Scanner / Indexer  │
 (на вашем HDD)     │         │           │
                    │         ▼           │
                    │      SQLite         │
                    │         │           │
                    │         ▼           │
                    │ HTTP + WebSocket    │
                    └─────────┬───────────┘
                              │
                     ┌────────┼────────┐
                     ▼        ▼        ▼
                   Browser   Phone    PC
```

GeoFrame **индексирует** вашу папку с фото — оригиналы остаются на месте. Кэш и метаданные — в data dir GeoFrame:

```
/mnt/HDD/Photos/              ~/.local/share/geoframe/
  IMG_0001.HEIC                 geoframe.db
  IMG_0002.MOV                  cache/thumbnails/
  ...                           cache/previews/
```

## Ключевые принципы

| Принцип | Решение |
|---------|---------|
| Хранение | Оригиналы сохраняются как есть |
| Просмотр | Web UI показывает preview, оригинал — по запросу |
| Обработка | Фоновая; библиотека доступна сразу после импорта |
| Удаление | Soft-delete в DB → восстановление или permanent delete с подтверждением |
| Файлы | Index mode: оригиналы на диске пользователя, GeoFrame их не копирует |
| Бэкапы | Ответственность пользователя; бэкапить source folder + `geoframe.db` |
| AI | Не часть MVP; решения по сериям и дубликатам принимает человек |

## Основные возможности (целевое состояние)

### Навигация и просмотр

- Галерея с mobile-first веб-интерфейсом
- **Карта** — одна из центральных фич (кластеры по местам, клик → фото)
- Просмотр фото/видео/Live Photo как единых объектов
- Полный EXIF по запросу (может генерироваться на лету)

### Организация

- Группировка по дате, месту, стране
- Избранное (метаданные GeoFrame, не изменение файла)
- Фильтры (детали — позже)

### Инструменты очистки

- **Точные дубликаты** (SHA-256) — отдельный раздел
- **Серии** — группировка по времени (~3 сек между соседними кадрами); пользователь выбирает, что оставить
- Почти-дубликаты, визуально похожие — не в MVP

### Медиа

- Фото: JPEG, HEIC/HEIF, PNG, WebP, AVIF, TIFF, RAW
- Видео: MOV, MP4 и другие распространённые форматы
- Live Photo (HEIC + MOV) — один логический объект
- Apple Burst — распознавание связей

## Установка (целевое состояние)

```
Download → Install → "Where is your library?" → Start
```

Без Docker, без ручной настройки PostgreSQL. Один инсталлер — готовый сервер.

## Сценарии использования

| Сценарий | Приоритет |
|----------|-----------|
| Laptop → localhost | Сейчас |
| Домашний сервер / NAS → LAN | Ближайшее |
| Доступ извне дома | Главный конечный сценарий |

## Безопасность (целевое состояние)

- Passkey — идеальный вариант, но не обязательный
- Несколько пользователей возможны, но «одна установка = одна библиотека» — нормальная модель
- Внешний доступ — максимально простой для пользователя (технология TBD)

## Что GeoFrame **не** делает

- Не заменяет систему резервного копирования
- Не редактирует и не переименовывает файлы (кроме Trash и добавления GPS с предупреждением)
- Не использует AI для выбора «лучшего кадра»
- Не является Telegram-ботом (старая концепция отменена)
