# GeoFrame — дорожная карта

Будущие фичи, отсортированные по приоритету. Всё, что не в [MVP](CURRENT.md), — здесь.

## Фаза 2 — доступ и удобство

### Удалённый доступ

- **Главный конечный сценарий**: открыть библиотеку извне дома
- Технология TBD: домен + HTTPS, VPN, или встроенный туннель
- Требование: максимально просто для обычного пользователя

### Авторизация

- Passkey — предпочтительный вариант
- Не должен быть блокером для пользователей без passkey
- Альтернативы: username/password, PIN, magic link

### Инсталлер

```
Download → Install → выбрать папку → Start
```

- PostgreSQL, сервер, thumbnails — всё внутри, пользователь не настраивает
- Поддержка: Windows, macOS, Linux
- Docker Compose — опционально для продвинутых

## Фаза 3 — импорт и загрузка

### Web upload

- Загрузка фото с телефона через браузер
- Пакетная загрузка (50+ файлов)

### USB-импорт

```
iPhone detected
3 482 new photos, 836 videos
[ Import all ]
```

- Определение уже импортированных (по hash)
- Пропуск дубликатов
- Только новые файлы

### Импорт из существующей папки (режим A)

- Индексация без копирования (watch folder)
- Права доступа: папка read-only для пользователя ОС

## Фаза 4 — навигация и фильтры

### Фильтры

```
Date → Country → Location → Camera → Media type
```

- Комбинируемые фильтры
- Favorites, Series, Duplicates как быстрые фильтры

### Timeline

```
2026
  September — 1,283 photos
  August — 842 photos
    └── Belarus → Ushachy → June 24 — 184 photos
```

### Поездки (Trips)

- Автоматическая группировка по географии и времени
- Ручная корректировка границ поездки

## Фаза 5 — геолокация

### Reverse geocoding

```
GPS → Belarus → Vitebsk region → Ushachy
```

- Использование в фильтрах и подписях
- Кэширование результатов

### Ручное указание места

```
Photo → Location: Unknown → [ Set location ]
```

- Добавление GPS к фото без координат
- **Предупреждение**: изменяет оригинальный файл

### Timezone

- Учёт часового пояса при группировке по дням
- Только при наличии надёжного источника

## Фаза 6 — инструменты очистки (расширенные)

### Почти-дубликаты

- Один снимок, разный размер / compression / metadata
- Отдельная категория от точных дубликатов

### Визуально похожие

- Perceptual hash (phash уже есть в коде)
- Группировка без автоматического удаления

### Улучшенные серии

- Учёт Burst mode (Apple)
- Более умные алгоритмы (не только time proximity)
- Без AI-рекомендации «лучшего кадра» — решение за человеком

## Фаза 7 — социальное и мультипользовательское

### Sharing

```
Select photos → Share → Generate link
https://... (expires: 7 days)
```

- Просмотр без аккаунта
- Ограниченный срок действия

### Несколько пользователей

- Одна установка — несколько библиотек / пользователей
- Альтернатива: две установки на разные папки

## Фаза 8 — медиа (расширенное)

### Форматы

- RAW: CR2, CR3, NEF, ARW, DNG
- WebP, AVIF, TIFF
- Дополнительные видеоформаты

### Видео

- Streaming оригинала
- Web-совместимый transcoding (если браузер не воспроизводит)
- Poster frame, codec, FPS в UI

## Фаза 9 — AI (дальняя перспектива)

> Не часть ближайших планов. Основная ценность GeoFrame — без AI.

Потенциально в будущем:

- Семантический поиск: «фото с собакой у машины»
- Распознавание лиц
- Автотегирование по содержимому
- «Лучшие фото из поездки»

## Фаза 10 — надёжность

### Мониторинг диска

- Индикатор заполнения
- Блокировка импорта при нехватке места
- Автоочистка кэшей (thumbnails, previews)

### Документация по бэкапам

GeoFrame **не делает бэкапы**, но должен чётко объяснять:

```
Что бэкапить:
  ✅ Library/originals/     — ваши фото (критично)
  ✅ PostgreSQL database    — метаданные, избранное, серии
  ⚠️  thumbnails/previews   — можно перегенерировать
```

## Явные non-goals

- Облачный SaaS с подпиской
- Редактор фотографий
- Социальная сеть / лента
- Замена Apple Photos / Google Photos как синхронизация с телефоном
- Telegram-интеграция (отменена)

## Как читать этот документ

Фазы — ориентир, не жёсткий план. Приоритеты могут сдвигаться по мере разработки MVP и обратной связи. Любая фича из roadmap должна проходить через призму:

1. Нужна ли она для self-hosted photo library?
2. Можно ли обойтись без неё ещё один релиз?
3. Не противоречит ли принципу «человек принимает решения, не AI»?
